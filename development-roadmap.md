# ArchForge development roadmap

**Development Status: In Progress**

This is a phased plan for proposed development.

### Phase 1: Foundation

Define the requirement schema, a reference workload, and a small catalog of reviewed AWS patterns.

### Phase 2: Core system

Generate an architecture model, diagram, and Terraform draft from validated inputs.

### Phase 3: Evaluation

Integrate Terraform validation, security rules, and assumption-based cost estimates.

### Phase 4: Hardening

Add reviewer feedback, versioned artifacts, more patterns, and reproducible evaluation cases.
